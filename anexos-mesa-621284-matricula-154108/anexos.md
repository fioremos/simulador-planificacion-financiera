# Anexo - "Framework y Nosw JS"
## Frameworks y herramientas de desarrollo con JavaScript

JavaScript es uno de los lenguajes de programación más utilizados en el desarrollo web moderno, debido a su versatilidad y a la posibilidad de ser ejecutado tanto del lado del cliente como del lado del servidor. Gracias a su ecosistema, existen múltiples frameworks y herramientas que facilitan la creación de aplicaciones web completas, escalables y mantenibles.

### Desarrollo frontend con JavaScript

En el frontend, JavaScript se apoya en frameworks y librerías que permiten construir interfaces de usuario dinámicas e interactivas, mejorando la experiencia del usuario y la organización del código. Entre las más utilizadas se encuentran:

- **React**: librería basada en componentes reutilizables, muy utilizada en aplicaciones de tipo SPA.
- **Angular**: framework completo que ofrece una estructura robusta para aplicaciones de gran tamaño.
- **Vue.js**: framework progresivo que combina simplicidad y flexibilidad.

Estas herramientas permiten actualizar la interfaz sin recargar la página y facilitan el mantenimiento del código a largo plazo.

---

### Desarrollo backend con JavaScript

JavaScript también puede utilizarse del lado del servidor gracias a Node.js, un entorno de ejecución que permite manejar múltiples peticiones de forma asincrónica y eficiente. Para simplificar el desarrollo backend, se utilizan frameworks como:

- **Node.js**: entorno de ejecución para JavaScript del lado del servidor.
- **Express.js**: framework minimalista que facilita la creación de servidores web y APIs REST.

Estas herramientas permiten estructurar el backend, manejar rutas, validar datos y conectar la aplicación con bases de datos.

---

### Stack MERN

El stack **MERN** es un conjunto de tecnologías basadas en JavaScript que permiten desarrollar aplicaciones web completas utilizando un único lenguaje en todas las capas del sistema. Está compuesto por:

- **MongoDB**: base de datos NoSQL orientada a documentos.
- **Express.js**: framework backend para la creación de APIs.
- **React**: librería frontend para interfaces dinámicas.
- **Node.js**: entorno de ejecución del servidor.

Este stack se destaca por su flexibilidad, escalabilidad y enfoque en componentes reutilizables.

---

### Stack MEAN

El stack **MEAN** también está basado íntegramente en JavaScript, pero utiliza Angular como framework frontend. Está compuesto por:

- **MongoDB**
- **Express.js**
- **Angular**
- **Node.js**

MEAN ofrece una arquitectura más estructurada y definida, lo que resulta beneficioso en aplicaciones grandes o entornos empresariales.

---

### Comparación MERN vs MEAN

| Característica | MERN | MEAN |
|---------------|------|------|
| Frontend | React | Angular |
| Tipo | Librería | Framework completo |
| Curva de aprendizaje | Media | Alta |
| Flexibilidad | Alta | Media |
| Uso común | Aplicaciones modernas | Aplicaciones empresariales |

---

### Conclusión

Tanto MERN como MEAN son stacks robustos para el desarrollo de aplicaciones web con JavaScript. MERN ofrece mayor flexibilidad y simplicidad, mientras que MEAN proporciona una estructura más rígida y completa. La elección entre uno u otro dependerá de los requerimientos del proyecto, el tamaño del sistema y la experiencia del equipo de desarrollo.
